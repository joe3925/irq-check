Method
- Each setting released all 18 ready workers together. Settings ran as separate batches.
- All packages used default features. These are not chain-64 or writer-growth large runs.
- No memory or time limits were used.
- Each individual setting enabled only its named change. The baseline disabled all four changes but retained shared storage-ID and empty cache infrastructure. It is not the historical binary.
- Values below are individual driver peak commit in decimal MB, read from Windows before driver exit. They are not simultaneous whole-machine memory peaks. Do not add them to infer a batch peak.
- Each cell is one run. Concurrent scheduling and allocation can affect results. Small differences need repeat runs.
- Retained context counts are not total-ever-created context counts.

Outcomes
- All 108 result files are present.
- Each setting passed 16 IRQ scenarios and built the helper library: 102 exit-zero runs.
- Default kernel-memory returned incomplete analysis in all six settings: six exit-101 runs. It produced 19 to 21 incomplete-analysis errors per run. No setting established a policy verdict for that case.
- No compiler-error or panic marker was found by the runner.
- The command exited 1 during the last report append because performance/results.txt was locked. Analysis results were already saved. This report recovers the complete matrix; the append failure is not an analysis failure.

Conclusion
- Collection has the largest measured individual benefit. It also reduced formatting peak commit from 396115968 to 385167360 bytes and retired 154 contexts there.
- Atomic, argument, and tree changes do not show a broad peak-memory benefit in this batch. Each had a higher peak in some cases. The largest observed increase was tree cleanup on context-growth, at 2.53 percent.
- These single-run increases are candidates for repeat measurement, not proof of a stable regression.
- Combined context-growth peak fell 14.36 percent. Most other passing cases changed little. This does not establish a full-kernel memory reduction or removal of paging.
