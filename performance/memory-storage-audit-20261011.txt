The earlier memory reduction did not establish convergence. The old kernel

Three further change groups are now implemented:

1. Tree sharing checks for an equal tree under a read lock. A miss takes the
   write lock and checks again before insertion. Full equality is still
   required; the hash is not accepted as proof of equality.

2. Fact storage copies a snapshot under a read lock, then computes the update
   and its differences outside the write lock. Commit checks object identity
   and version. If either changed, the operation retries from a new snapshot.
   The update callback has no external side effects. Committed differences,
   not a failed attempt, control publication and redundant-write accounting.

3. The worker applies its existing live-state and partition preparation at
   enqueue as well as dequeue. It rejects states already seen or covered by
   the widened state for that location and partition. It also removes covered
   queued states when widening advances. Queue scans are rate-limited by queue
   growth. The widening thresholds and reference limits are unchanged. The
   counters covered-pending-states and pruned-pending-states show this work.
   Scratch storage is reused, rather than allocated for each preparation.

Causes and changes

1. Copy-on-write maps copied spare capacity after entries were removed.
   Flow maps and tree maps now copy live entries when capacity is excessive.
   Unique maps and fact sets are compacted at state storage points. Shared
   maps are not copied only to compact them.

2. Equal memory shapes had separate map allocations.
   memory_shape now returns a shared clone when the result equals its input.
   Equality covers the complete state. Later writes still use copy-on-write.

3. Small trees were excluded from sharing. Trees were shared too late, after
   queued states had already accumulated. Binding and context stamping then
   made new copies of trees that had been shared earlier.
   The shared weak pool now accepts all tree sizes. States are processed
   before enqueue. Arguments, return values, and bound context memory are
   shared after their final transformation. A hash only selects candidates;
   pointer identity or full value equality is required before reuse.

4. Reference caches contained duplicate bases and spare vector capacity.
   Reference lists now keep each base once, in first-seen order, and release
   spare capacity. Graph edge vectors release capacity after deduplication.
   Captured graph vector requests fell from 417,418,176 to 22,307,600 bytes.

5. bind_tree built a fact set, then copied it into a second set to normalize
   it. It now normalizes the first set in place and removes excess capacity.

6. join_facts inserted numeric facts that an existing Unknown fact would
   immediately remove. It now skips those insertions. It also releases
   excess capacity after the existing reduction. The existing threshold of
   eight numeric facts is unchanged. Reference and function facts are kept.

can still raise private memory later in the run. These changes reduce known
waste; they do not prove a fixed memory bound or full kernel convergence.
